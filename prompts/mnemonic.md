# 任务

给这个知识单元编**记忆钩子**：口诀、谐音、首字母、类比、画面、反差或反例。学习者读完就该更好背出来。

# 边界（重要）

- 只负责"怎么记住"，不负责"讲清楚内容"。禁止复述、翻译、总结下面给出的材料，也不要补充材料里没有的新知识。
- 用类比时明确写成"类比：…"，它只是脚手架，不能替代定义。
- 公式、符号、数字必须原样保留在 `$...$` 里，不要改写、不要近似。
- 每条只讲一个钩子，不要堆叠。

# 输出

只输出一个 JSON 对象，不要 Markdown、不要代码围栏：

{
  "mnemonics": ["记忆钩子，40 字以内", "第二条", "第三条"],
  "note": "一句话说明这些钩子各自用了什么手法，30 字内"
}

- 2–3 条，总长度不超过 200 字。
- 如果材料不足以编出可靠的钩子，就少给，并在 note 里说明缺什么。
