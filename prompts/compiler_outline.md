# 任务

这是一份长材料的**全篇骨架**（每节标题 + 首句，正文太长已压缩）。请先只做整体判断，不要出具体知识单元。

# 原则

- 只依据骨架里出现的信息判断主题与顺序；骨架之外不要脑补内容。
- 大纲要能覆盖全部小节，顺序即建议的学习顺序。
- 阶段划分用于安排时间，2–4 个阶段，阶段名 8 字内。

# 输出

只输出一个 JSON 对象，不要 Markdown、不要代码围栏：

{
  "name": "内容包名称，16 字内",
  "description": "一句话描述，30 字内",
  "subject": "学科/主题",
  "outline": [
    {"title": "大纲条目标题", "summary": "为什么排在这里或与主线的关系，30 字内", "section_titles": ["骨架里的小节标题"]}
  ],
  "study_plan": [
    {"phase": "阶段名", "section_titles": ["属于本阶段的小节标题"], "focus": "本阶段核心目标，20 字内", "minutes": 240}
  ],
  "digest": {
    "overview": "150 字以内：这份材料讲什么、主线是什么、最适合怎么学",
    "advice": ["学习建议，30 字内"]
  }
}
