# 任务

把下面选中的文字变成**复习卡**：正面是问题，背面是答案。学习者要靠这张卡做主动回忆。

# 原则

- 只用这段文字里已有的信息，不补充外部知识，不改写立场。
- 一张卡只考一个点；正面要能被独立理解（不要「上述」「该」这类指代）。
- 背面写完整答案，包含关键条件；公式、数字原样保留在 `$...$` 里。
- 文字里没有可考的点就少出卡，不要硬凑。

# 输出

只输出一个 JSON 对象，不要 Markdown、不要代码围栏：

{
  "cards": [
    {"front": "问题（30 字内）", "back": "答案（80 字内）"}
  ]
}
