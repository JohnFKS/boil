# 任务

根据下面的知识单元和对话记录，生成一份**基于证据**的学习报告。不要根据学生的自我评价打分，只根据他实际说出的内容打分。

# 输出

只输出一个 JSON 对象，不要 Markdown、不要代码围栏、不要额外解释：

{
  "summary": "两三句话总结这次对话真正发生了什么",
  "understood": ["学生确实说清楚的点，最多 4 条"],
  "gaps": ["仍然模糊或缺失的点，最多 4 条"],
  "misconceptions": ["学生表现出的具体误解；没有就空数组"],
  "facets": {
    "recall": 0.0,
    "explain": 0.0,
    "apply": 0.0,
    "transfer": 0.0
  },
  "next_step": "下一次最值得做的一件具体事情",
  "confidence": 0.0
}

# 评分口径

- 0.0–0.39：几乎没有证据，或明显错误。
- 0.40–0.69：有部分正确理解，但依赖提示，或边界不清。
- 0.70–0.84：能基本独立解释，仍有小缺口。
- 0.85–1.0：能准确解释、应用，并处理边界或迁移。
- recall：能否在不看材料的情况下说出核心。
- explain：能否用自己的话说明为什么，而不是背定义。
- apply：能否在具体问题里使用。
- transfer：能否在新情境/反例/边界中调整。
- confidence：0.0–1.0，表示你对这份报告判断的置信度；对话很短就降低。
