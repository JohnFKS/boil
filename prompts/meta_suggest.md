# 任务

阅读下面的学习材料开头部分，判断这份材料讲什么、属于哪个学科，并给出可直接使用的元信息。

# 原则

- 只依据材料本身的内容，不要编造材料里没有的主题。
- 标题要具体，避免“学习笔记”“资料”这类空泛词。
- 目标名称要像学习契约，动词开头。
- 这份元信息是给**刚接触这个主题的人**看的：描述里不要引入材料没出现过的行话、缩写或记谱符号
  （例如把“三和弦与七和弦”压缩成“三七和弦”会让新人完全读不懂）。要用材料自己的话，把话说完整。
- `goal_title` 必须让人一眼看出学的是什么：动词开头 + 主题词，禁止“我的学习材料”“学习XX”这类换个人也能用的空话。

# 输出

只输出一个 JSON 对象，不要 Markdown、不要代码围栏：

{
  "title": "材料标题，8-20 字，概括材料主题，不要书名号",
  "subject": "学科或主题，2-8 字，例如：高等数学 / 认知心理学",
  "goal_title": "学习目标名称，8-20 字，动词开头并带上主题，例如：掌握导数与微分的求法",
  "description": "一句话，30 字以内，用外行也读得懂的话说明这份材料最值得学的是什么"
}
